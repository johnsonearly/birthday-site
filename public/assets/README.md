# Assets

Replace the placeholders by dropping files in with the same names (or edit paths in `src/data/birthdayContent.ts`).

- `intro/intro-01.jpg … intro-07.jpg` — fly-in photos (portrait 4:5 works best; 5 are used on mobile)
- `gallery/gallery-01.jpg … gallery-07.jpg` — 3D gallery (any aspect ratio, ~1600px wide max)
- `friends/friend-01.jpg …` — square profile photos (~256px)
- `decorations/` — optional extra decoration art
- `audio/soundtrack.mp3` — optional background music (never autoplays; shown only if the file exists)

Missing images automatically fall back to a purple placeholder.
